# 데이터 출처 및 재배포 범위

아래 내용은 팀 발표자료(p. 35–36), 첨부자료와 Notion 조사 페이지의 출처 표기를 정리한 것이다. 일부 공공데이터포털의 현재 이용허락 표시를 확인했으나 당시 파일별 재배포 승인 및 단체 산출물 공개 범위는 확정되지 않았다. 출처 표기가 사용·재배포 권한을 뜻하지는 않는다. 확인 결과는 [데이터 카탈로그](data-catalog.md)를 참고한다.

| 분야 | 팀 자료에 기록된 출처 | 공개본 처리 |
| --- | --- | --- |
| 전세보증 사고 | 주택도시보증공사(HUG), 공공데이터포털 | 데이터 미포함 |
| 전세사기 피해자 통계 | 지자체 정보공개 관련 자료 | 원본 및 세부 집계 미포함 |
| 실거래가·전세가율 | 국토교통부 실거래가 공개시스템 | 원본·가공 데이터 미포함 |
| 저당권 | 등기정보광장 | 데이터 미포함 |
| 주택소유통계 | 국가데이터처, KOSIS | 데이터 미포함 |
| 병원·교육시설·상업시설·공원·교통 | 각 지자체 포털, NEIS, LOCALDATA, 공공데이터포털, 문화 빅데이터 플랫폼 | 데이터 미포함 |
| 범죄 관련 지표 | 행정안전부 생활안전지도(경찰청 제공) | 지도/데이터 미포함 |

실거래가 원본에는 외부 공개 시 신고일 기준 공식 통계를 사용하라는 안내가 있었다. 주소·번지·단지명·층·계약일 등 조합은 일반 거래를 다시 식별할 위험이 있어 공개하지 않는다. 기관 협조 요청 문서는 교육 프로젝트 목적의 요청으로, 재배포 승인을 확인하는 문서가 아니다. 실거래 기반 가상자료도 실제 원천을 기반으로 하므로 완전 합성 여부와 공개권한을 확인하기 전에는 제외한다.

## 팀 발표에 기재된 참고 연구

- 김진유(2022), 고위험 전세와 전세보증금 미반환 위험의 상관관계 분석 - 서울시 전세보증사고를 중심으로.
- 김정한·이정란(2024), 지역 및 주택 특성에 따른 고위험전세 발생 위험 분석.
- 노주희(2023), 전세보증금반환보증 사고 결정요인에 관한 연구.
- 국토교통부(2023), 전세사기 피해 실태조사 결과 보고서.
- 서울특별시(2025), AI 기반 전세사기 위험분석 보고서 서비스.

위 서지사항은 팀 발표에 나온 항목으로, 각 원문과 최신 서지는 별도 확인하지 않았다.

## 현재 공개 패키지에 포함하는 데이터

원본 데이터는 **없다**. `src/synthetic.py`가 실제 자료·지리 정보와 무관한 합성 행을 메모리에서 생성한다. 데이터 원본, 팀원 식별 정보, 공문, 발표 화면 및 지역 순위는 포함하지 않았다.
