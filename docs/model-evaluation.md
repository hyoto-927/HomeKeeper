# 모델 검증 회고 및 개선안

## 원 프로젝트 결과에 대한 판단

직접 읽은 CSV 3개에서 심의가결여부의 0/1 라벨은 학습용·전처리 각각 264,745 / 35,255 (양성 비중 11.75%), 100건 테스트는 88 / 12였다. 이는 **심의가결 라벨 분포**이지 실제 사기율이 아니며, B_test 원 파일과 동일하다고 단정하지 않는다. 이전 회의 기록에서 B_test의 사기 탐지가 부진하고 클래스 불균형 문제가 관찰되었다. 높은 정확도가 소수 클래스 탐지 성공을 보장하지 않으므로 정밀도·재현율·PR-AUC·혼동행렬을 확인하는 것이 중요하다.

| 관찰 | 해석 |
| --- | --- |
| 초기 분류용 파일에서 보험가입 상태와 심의가결 상태가 항목별로 완전히 일치 | 정답과 사실상 동일한 피처로 인해 성능이 과대평가될 수 있음. 두 변수의 생성 경위와 실제 레이블을 확인해야 함 |
| 초기 모델 발표 화면의 높은 점수 및 중요도 표에 심의가결여부 등장 | 타깃 혹은 사후 대리변수를 입력했는지 코드 확인 필요. 지표 재현 불가 |
| 지역 통계에 피해 건수·거래 건수와 피해 비율이 공존 | 동기간 비율을 직접 계산하거나 근사하는 누수 위험. 실제로 해당 변수들이 훈련에 투입됐는지는 확인 불가 |
| 실거래 기반 가상데이터 및 독립 테스트의 출처·생성 로직 불명 | 실제 피해 발생 예측으로 일반화할 근거 부족 |
| 발표의 일부 MAPE가 비정상적으로 큼 | 타깃 0/극소값이 있을 때 MAPE 해석이 불안정할 수 있으므로 MAE/RMSE와 목표 분포 우선 확인 |

이것은 첨부파일의 구조를 검토한 결과이지 원 모델을 재학습하거나 독립 검증한 결과가 아니다. 발표상 점수는 검증된 성과로 인용하지 않는다.

## 독립 평가 절차

1. 목표 정의·라벨의 생성 시점 및 출처를 확정하고 직접 또는 간접 대리변수를 제외.
2. 지역 중복과 시간 역전을 방지한 테스트 세트 고정. 전처리, 모델 선택, 하이퍼파라미터 탐색은 훈련 세트의 내부 교차검증에서만 수행.
3. 단순 평균·가중합·선형회귀와 트리 기반 모델 비교. 미래 피해율 회귀 문제에는 MAE·RMSE·R²와 표본 규모, 성능의 구간별 차이를 확인.
4. 개별 분류 모델을 다시 설계할 경우 독립 실측 라벨과 사전 관측 가능한 피처를 사용하고 PR-AUC, 정밀도·재현율, 보정 곡선 등을 함께 검토. 지역 위험률과 혼동 금지.
5. 외부 시점/지역 검증, 오차·불확실성·작은 표본 문제, 지역별 왜곡 여부를 확인한 후에만 추가 서비스 실험 검토.

## 이 저장소의 실행 예제

가상의 40개 구역과 24개 월을 생성한다. 구역 0~29의 월 1~15를 학습에 사용하고, 구역 30~39의 월 17~24를 평가에 사용한다. 목표는 각 행 관측월보다 한 달 이후이며 학습 목표월과 평가 관측월이 겹치지 않도록 월 16의 관측 행은 학습에서 제외한다. 나머지 사용하지 않은 지역/시점 조합은 평가에서 제외한다.

모델은 훈련 평균, 예시 가중 신호에 대한 선형 보정, 선형회귀, Random Forest, Gradient Boosting이다. 결과는 **합성데이터에서 코드가 실행되는지 확인하는 예제 지표**에 한정되며 실세계 성능과 무관하다. 모델 파라미터는 예제용으로 사전에 고정했다. 모든 변환은 훈련 데이터에만 적합하며 실제 데이터 관련 성능을 주장하지 않는다.

### 실행 확인 (가상 데이터만)

Python 3.12, scikit-learn 1.9.1로 독립 예제를 실행했다. 훈련 450행 및 평가 80행이며, 단위는 합성 목표 비율의 0~1 척도이다.

| 모델 | MAE | RMSE | R² |
| --- | ---: | ---: | ---: |
| 훈련 평균 | 0.0759 | 0.0907 | -0.0995 |
| 예시 가중 지표 | 0.0536 | 0.0669 | 0.4021 |
| 선형회귀 | 0.0529 | 0.0673 | 0.3948 |
| Random Forest | 0.0567 | 0.0731 | 0.2858 |
| Gradient Boosting | 0.0549 | 0.0700 | 0.3451 |

이 수치는 원 프로젝트 결과가 아니다. 한 번의 합성 홀드아웃으로 모델의 일반적 우열을 판단하지 않으며, 전체 동작 확인용 단위 테스트 9개가 통과했다.

추가로 `python -m src.contract_demo`는 학습·시험 간 가정이 달라진 가상 분포에서 소수 클래스 평가를 시연하고, `python -m src.score_review`는 발표의 여섯 항 산술 및 임의 점수 방법의 Top10 교집합을 계산한다. 각 결과는 해당 예제의 출력일 뿐 원 프로젝트의 B_test·Top10 기록과 동일하지 않다.

### 추가 합성 데모 실행 결과

가상 계약 예제의 학습 6,000개 중 양성 471개, 시험 3,000개 중 양성 58개. 예제 시험은 고의로 생성 가정을 바꾼 별도 합성 분포다.

| 예제 모델 | Accuracy | Precision | Recall | Average Precision | TN / FP / FN / TP |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기본 로지스틱 회귀 | .9807 | .0000 | .0000 | .0129 | 2942 / 0 / 58 / 0 |
| 클래스 가중 로지스틱 회귀 | .5747 | .0089 | .1897 | .0129 | 1713 / 1229 / 47 / 11 |

첫 모델은 높은 정확도에도 양성을 한 건도 검출하지 못했다. 두 번째는 재현율이 높아지지만 오탐 증가와 낮은 AP를 보인다. 실제 B_test 지표의 복원이 아니라 왜 불균형·분포 변화가 문제인지 시연하는 예제다.

| 가상 30개 구역 Top10 교집합 | 여섯 항 가중합 | 동일 가중합 | 단일 지표 |
| --- | ---: | ---: | ---: |
| 여섯 항 가중합 | 10 | 9 | 4 |
| 동일 가중합 | 9 | 10 | 4 |
| 단일 지표 | 4 | 4 | 10 |

이 표의 ID·값은 실제 지역과 무관하다. 10은 동일 방법의 자기 교집합이며, 순위 겹침은 정답률이 아니다.
