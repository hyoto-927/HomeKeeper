# 가상 데이터 설계와 검증의 경계

## 1. 실제 자료에서 가상 계약·법정동 지표로

이전 회의 기록을 정리한 대화에서는 실거래가와 지역별 거래 분포를 참고하여 가상 계약 정보와 위험점수를 생성하고, 전세사기 여부 및 심의 가결 여부를 가상 라벨로 부여한 뒤 법정동으로 집계하는 설계가 확인되었다. 이는 실제 피해자를 표본으로 관측해 라벨링한 것과 다르다. 원본 생성 스크립트, 난수 시드 및 모든 가정의 수치는 ZIP에 없어 그대로 실행할 수 없다.

| 단위 | 역할 | 확인 수준 |
| --- | --- | --- |
| B_train | 가상 계약 단위 분류 학습 | 이전 대화의 회의 기록 요약. 첨부 30만 행 개별·전처리 파일이 존재하나 명칭 일대일 대응 미확인 |
| B_test | 학습과 분리하여 분류 탐지 평가를 시도 | B_test에서 사기 탐지가 부진했다는 기록. 클래스 불균형 문제; 정확한 혼동행렬·파일 대응 미확인 |
| A_realistic | 실제 거래 분포와 가상 지표를 연결한 동 단위 분석 및 점수 산출 | 실거래 기반 가상 지역 CSV 존재. 독립적인 실측 사기 검증 세트가 아님 |

실제 피해 자료가 없어 가상 라벨을 생성하는 데 설정한 위험점수·상관구조를 모델이 다시 학습하는 실험이었다. 훈련과 시험 표본을 분리하더라도 같은 가정으로 만들어진 라벨을 재현하는 성능은 현실의 사기 예측 성능으로 해석할 수 없다.

## 2. 상관관계와 분위수 매핑

- 상관관계 설계: 선행연구·위험 요인의 방향을 참고하여 생성 변수의 동반 변동을 설정하였다. 회의 기록 요약에 기존/v5.0 상관계수 비교가 등장한다. 설정 계수 또는 가상 데이터에서 계산한 값은 실제 피해 표본의 실측 상관계수가 아니다. 수치와 생성기의 정합성은 미확인이다.
- 분위수 매핑(Quantile Mapping): 팀원별 데이터의 척도 차이를 통합하기 위해 분포의 순위·분위수를 기준으로 기준 분포에 맞추는 방식이 논의되었다. 예를 들어 기준 분포의 80번째 백분위에 대응되는 값을 다른 분포의 80번째 백분위 값으로 매핑한다. 이는 분포를 유사하게 보이도록 하는 방법이지 계약 단위 실제 값의 복원이나 인과관계 검증이 아니다. 실제 적용 열·참조 집합·타이 처리·보간·시점은 확인되지 않았다.
- 법정동 집계: 계약 단위 라벨을 합산하고 거래수를 분모로 한 비율을 생성하는 구상이다. 거래가 없는 지역에서 비율은 관측 불가로 취급해야 한다. 첨부 실거래 기반 가상 CSV에서 거래수가 양수인 2,116행 모두 사기건수 / 전세거래건수 × 100과 저장된 사기율이 허용오차 0.01%p 이내였다. 이는 집계의 산술 정합성을 확인할 뿐, 사기 건수의 실측 여부를 입증하지 않는다.

## 3. FINAL_v4: 발표 코드 화면과 대조

발표자료 p. 17의 `FEATURE_WEIGHTS` 및 누적 코드에서 아래 여섯 항목을 직접 확인했다. 같은 이름의 여섯 지표가 첨부 법정동 CSV의 열에 존재한다. **아래 숫자는 발표의 설계 가중치이며 통계적으로 추정된 계수 또는 피해 발생 확률이 아니다.**

| 코드 화면의 지표 | 가중치 |
| --- | ---: |
| 관할동_고근저당비율(%) | 0.15 |
| 관할동_평균_전세가율(%) | 0.15 |
| 관할동_보증보험거절률(%) | 0.12 |
| 관할동_신축빌라비율(%) | 0.10 |
| 관할동_경매건수 | 0.08 |
| 관할동_경매유찰건수 | 0.05 |
| **합계** | **0.65** |

CSV에서는 경매건수 열에 `(은행-개인부채)`가 붙는다. 원본의 renaming·정규화 코드가 없으므로 실제 계산 전 이름 매칭·스케일 변환을 확인해야 한다. 화면의 코드는 열 존재 확인 후 `동별_종합위험도_FINAL_v4`를 0으로 초기화하고 각 열 × 가중치를 순차 합산한다. 화면에는 0~1 정규화를 권장하는 주석이 있으나 실제 정규화된 입력 파일이나 합계 0.65를 1로 재조정했는지 여부는 확인되지 않는다. 이 저장소의 `src/score_review.py`는 화면의 산술만 독립적으로 구현한 예제이며 0~1 입력에서 최대 0.65이다. 원 코드의 전처리나 결과를 복원한 것이 아니다.

## 4. Top10 교차 비교

발표 p. 16에서 가중치 미적용 모델별 Top10, p. 19에서 가중치 적용 결과, p. 20에서 가중치 전후 Top7 변화가 제시되었다. 이전 대화의 회의 기록 요약에 모델별 Top10 교차 비교 매트릭스 코드가 등장하지만 실행 파일과 원 매트릭스는 제공되지 않았다. 모델별 상위 10개 집합의 교집합 크기를 비교하는 재구성 예제를 제공한다. 동일한 표본의 동률을 결정론적으로 처리하며, 일치도가 높은 것은 모델들이 비슷하게 정렬함을 의미할 뿐 실제 위험지역을 맞혔음을 의미하지 않는다. 원 위치 및 순위는 공개하지 않는다.

## 5. 이 저장소와 원 프로젝트의 관계

`src/score_review.py`는 발표 가중합의 산술과 가상 ID Top10 비교를; `src/contract_demo.py`는 완전 가상의 계약 분포·라벨, 독립 분할·불균형 평가, 분위수 매핑 및 구역 집계를 새로 시연한다. 두 코드 모두 2026년 정리 시점에 작성된 예제이고 원본의 가상 데이터 생성 방식이나 원 모델의 성능 복원이 아니다.
