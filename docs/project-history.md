## 데이터 접근 제약을 해결하려 한 과정

계약별 피해 여부를 모델링하려면 계약 시점에 알려진 정보와 이후 피해 여부가 연결된 학습 데이터가 필요했다. 공개된 지역·연도별 보증 사고 통계는 도움이 되지만 계약과 피해의 일대일 대응을 제공하지 않는다. 팀은 필요한 데이터 항목을 정리해 외부 협조를 요청했으나, 핵심 계약별 학습용 데이터 확보에는 실패했다. 계약서 지참, 임대인 동의·통보, 심의 기준 비공개 등도 제약이었다(발표 p. 31). 따라서 전세사기 모델링에는 대부분 가상 데이터를 사용했다. 실제 실거래가·시설 정보와 가상 사기 라벨을 동일시하지 않는다.

## 기획·제안·구현·보완의 구분

| 구분 | 내용 |
| --- | --- |
| 초기 기획 | 개별 계약 사전 위험 진단, 유형별 주거비용 비교, 생활 지수, 정책 활용 |
| 회의 기록 요약 | 기관별 데이터 요청 목록, 가상 데이터 상관관계 설계 및 v5.0 비교, 분위수 매핑, 구조적 위험 파생변수, A/B 데이터 역할 분리, Top10 교차 비교 |
| 구현 증거 있음 | 실거래가 자료·가상 계약 및 법정동 집계 파일, 분류/회귀 비교 결과, FINAL_v4 스크린샷, 지도·범죄·생활 인프라 발표 화면 |
| 최종에서 제외 | 개별 계약 분류 모델은 최종 서비스에 사용하지 못함(발표 p. 33) |
| 구현 여부 미확인 | 유형별 관리비·실질 월세·가격 변동률을 모두 제공하는 기능; 회의 제안의 전체 적용; 실제 서버 운영 상태 |
| 후속 보완 | 데이터 계보 확정, 실제 피해 라벨 확보, 독립 평가·누수 제거, 불확실성 표시; 이 저장소의 새 합성 예제 |
