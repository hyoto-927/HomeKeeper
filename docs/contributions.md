# 팀의 분담 방식과 공동 성과

## 원 프로젝트 — 팀 활동 (발표자료 p. 4, p. 11)

| 활동 | 발표에서 확인한 팀 역할 분담 |
| --- | --- |
| 기획·보고서 | 주제 선정, 문서 및 보고서 작성 |
| 데이터 확보·처리 | 외부 데이터 수집, 웹 크롤링, 데이터 정제·정규화 |
| 외부 협조·모델링 | 기관 협조 요청, 모델 비교 및 분석 |
| 웹·DB | 웹페이지 구현 및 데이터베이스 구축 |
| 팀 운영 | 팀 리드, 산출물 조율 |

저를 포함한 다섯 팀원은 데이터 수집부터 전처리, 머신러닝 모델 실험, 최종 발표까지 단계별 작업을 나누어 맡았습니다. 위 표는 발표자료에 기록된 팀의 업무 범위입니다. 지도형 서비스와 발표는 이 작업들을 합친 팀 공동 산출물입니다.

## 이번 포트폴리오 정리에서 새로 만들어진 항목

README, 기술 회고 문서, 프로젝트 흐름도, 합성데이터 모델 평가 예제 및 테스트는 이번 포트폴리오 준비 과정에서 AI 지원을 받아 별도 제작한 산출물이다. 2025년 팀이 실제 작성한 원 코드나 개인 기여로 표기하지 않는다.
